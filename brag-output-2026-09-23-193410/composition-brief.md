# Composition Brief: Cryptonite

## Project Identity
- **Name:** Cryptonite
- **Format:** Landscape (16:9)
- **Tone:** Cinematic ("Big motion, bigger claims.")
- **Voiceover:** Enabled (Kokoro workflow)

## Visual Design (Obsidian Protocol)
- **Background Color:** `#0d1117` (Deep Obsidian)
- **Surface Color:** `#161b22`
- **Primary Text:** `#dfe2eb`
- **Accent/Brand:** `#10b981` (Neon Emerald)
- **Threat/Alert:** `#ef4444` (Rose Red)
- **Data/Scanning:** `#06b6d4` (Cyan)
- **Typography:** Display: `Inter`. Monospace: `JetBrains Mono`.

## Assets
- No external logo files required (Typography-led "CRYPTONITE").
- Terminal mockups and UI cards should be generated by Hyperframes using the palette above.
- The "cover image" can be a standard placeholder or synthetic nature shot from the Hyperframes library.

## Narrative Flow

**Scene 1: The Hook (0s - 4s)**
- **Visuals:** Pure `#0d1117` background. A clean placeholder image appears. A scanning line sweeps over it, briefly revealing "chaotic digital noise/bit-planes" before restoring the clean image. 
- **Typography:** `What you see is never all there is.` (JetBrains Mono, `#10b981`).
- **Voiceover Script:** "You think you're looking at a standard image. You're not."

**Scene 2: The Action (4s - 11s)**
- **Visuals:** Fast-typing terminal window. 
  - Code typing: `cryptonite embed -c cover.png -p secret.pdf`
  - AES-256 and ChaCha20 bars fill rapidly.
- **Typography:** `Military-grade steganography.`
- **Voiceover Script:** "Cryptonite embeds AES-256 encrypted payloads directly into PNG, JPEG, and MP3 files..."

**Scene 3: The Proof (11s - 17s)**
- **Visuals:** Web UI analysis screen. A radar/scan animation processes the file. 
  - Text pops up: `Chi-squared: Pass` | `SSIM: 0.99`
  - Big final verdict locks in: `VERDICT: SAFE (< 0.5% DETECTABILITY)` in `#10b981`.
- **Typography:** `Zero re-encoding artifacts. Statistically invisible.`
- **Voiceover Script:** "...and it completely bypasses real-time statistical steganalysis. Zero re-encoding artifacts. Statistically invisible."

**Scene 4: The Reveal (17s - 22s)**
- **Visuals:** Terminal quickly runs `cryptonite extract`. The screen clears and the word `CRYPTONITE` scales up powerfully in the center.
- **Typography:** 
  - Main: `CRYPTONITE`
  - Subtext: `Production-grade steganography.` | `Open source.`
- **Voiceover Script:** "Hide in plain sight. Cryptonite is open source and ready for production."

## Technical Constraints
- Keep scene pacing aligned with the voiceover.
- Ensure 0.3s per word read-time for on-screen typography.
- Export as `brag.mp4`. Output the poster frame to `brag.jpg` and bake it as frame 0.
